# ティラノンベースボール

ティラノンのワンタップ野球ゲームです。

## v0.1

- 10球勝負
- 画面タップ / スイングボタン / Space・Enter でスイング
- タイミング判定（空振り / ファウル / ヒット / ホームラン / ジャストミート）
- 飛距離表示
- 3連続ヒットでFEVER
- ランダムで「お肉ボール」が出現
- お肉ボールを打つと🍖を獲得
- スコア、ホームラン数、最高飛距離を結果表示
- ベストスコアをブラウザに保存
- 簡易効果音・ミュート
- スマホ対応

## 遊びの芯

「投げる → 待つ → タップ → カキーン → 飛距離が出る」の1球の気持ちよさを最優先にした初期プロトタイプ。

今後は実際のプレイ感を見ながら、投球の見やすさ、ジャストミート判定、ホームラン演出、ティラノンの正式素材、相手投手や報酬・育成要素を追加していく。
